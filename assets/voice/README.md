# Lalin / Raina ses varlıkları

Bu klasörde **gerçek ses dosyası henüz bulunmuyor**. `voice_picker_raina_ui.png` sadece ekran görüntüsüdür.

Kullanıcının Higgsfield'da beğendiği **Raina** kadın preset'i temel alınacak.

Kullanıcıdan veya yetkili kaynak üzerinden:
- `raina_test.wav` **veya** `raina_test.mp3` — gerçek Lalin test ses kaydı.
- Mümkünse `raina_pilot_line.wav` — pilot için `Ben senin fikrini değil, ışığını sordum.` repliği.
- Sonradan: `raina_laugh.wav`, `raina_breath.wav` ve doğrulanmış ses kimliği/ayar metadatası.

Ses dosyasını görmeden ses senkronu ve kahkaha animasyonu doğrulanmış ilan etme. Alternatif otomatik TTS/klonla sesi değiştirme. Metin denemesi `docs/07_PILOT.md` içindedir.
